# Snabbstart: Pusha till GitHub

Om du redan har skapat repositoryt `meanreverse` på GitHub, kör dessa kommandon:

## Steg 1: Öppna terminalen i projektmappen

## Steg 2: Kör dessa kommandon (ersätt DITT-ANVÄNDARNAMN)

```bash
git init
git add .
git commit -m "Initial commit: Mean Reverse Dashboard med lösenordsskydd"
git branch -M main
git remote add origin https://github.com/DITT-ANVÄNDARNAMN/meanreverse.git
git push -u origin main
```

**Viktigt:** Ersätt `DITT-ANVÄNDARNAMN` med ditt faktiska GitHub-användarnamn!

### Exempel:
Om ditt GitHub-användarnamn är `mattias123`, kör:
```bash
git remote add origin https://github.com/mattias123/meanreverse.git
```

## Steg 3: Autentisera

När du kör `git push` kommer GitHub att be dig logga in. Följ instruktionerna i terminalen.

## Klart! 🎉

Efter detta kommer alla dina filer att finnas på GitHub i repositoryt `meanreverse`.
